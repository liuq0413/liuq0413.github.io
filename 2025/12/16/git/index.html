git

git reset

git reset --soft <commit>

  • 撤销上一次提交，但保留所有更改在暂存区，方便你修改后重新提交。

git restore

  • 撤销 工作区​ 的修改（文件已修改，但未执行 git add）

git restore <file-path>

  1. 撤销 暂存区​ 的修改（文件已执行 git add，但未 git commit）

git restore --staged <file-path>

  • 等效旧命令：git reset HEAD <file-path>

git add

  • 添加文件到暂存区

git add <file-path>

git commit

  • 提交更改到本地仓库

git commit -m “message”

git push

  • 推送本地提交到远程仓库

git push [remote] [branch]

git pull

  • 从远程仓库拉取并合并更改

git pull [remote] [branch]

git status

  • 查看工作区和暂存区的状态

git status

git log

  • 查看提交历史

git log [options]

git diff

  • 查看文件差异

git diff [options]

git stash

  • 暂存当前工作区的更改

git stash [options]

创建git

git init

  • 初始化一个新的 git 仓库

git init [directory]

git clone

  • 克隆远程仓库到本地

git clone [url] [directory]

创建分支

  • 创建并切换到名为 “name” 的新分支。

git checkout -b name

git switch -c name

git branch

  • 分支管理

git branch [options]

git merge

  • 合并分支

git merge [branch]

git checkout

  • 切换分支或恢复文件

git checkout [branch|file]

git remote

  • 管理远程仓库

git remote [command]

git fetch

  • 从远程仓库获取更新但不合并

git fetch [remote]

git rebase

  • 变基操作，将当前分支的提交重新应用到目标分支上

git rebase [branch]

git tag

  • 标签管理

git tag [options]

git revert

  • 撤销指定提交，创建新的提交来反转更改

git revert [commit]

git reset 详细说明

git reset [mode] [commit]

删除远程remote

git remote -v

  • 删除名为 origin 的远程仓库：

git remote remove origin

git config

  • 配置 git 设置

git config [options]

git show

  • 显示提交的详细信息

git show [commit]

git submodule

  • 子模块管理

git submodule [command]

常用组合命令
